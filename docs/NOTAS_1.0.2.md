# SYN 1.0.2 — Icono nuevo integrado

## Novedades

- Se integra el nuevo icono minimalista de SYN.
- Pantalla curva sin fondo, con transparencia real.
- Sustituidos los iconos en todos los tamaños incluidos en el paquete:
  16, 24, 32, 48, 64, 96, 128, 256 y 512 px.
- Se conservan las mejoras de SYN 1.0.1:
  - color de realce funcional
  - restauración de la última vista/sección al abrir la app

## Verificación rápida

```bash
flatpak run com.mrseivane.Syn --version
```

Debe indicar `SYN 1.0.2`.
