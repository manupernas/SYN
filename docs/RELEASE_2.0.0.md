# SYN 2.0.0 — Linux

The new three-zone UI replaces the old SYN layout while preserving GTK4/libadwaita, the proven libmpv renderer, playlists, Xtream profiles, channel EPG, favourites, DVR scheduling, recordings, timeshift and Chromecast.

- Built-in DVR worker and Chromecast bridge: plug & play, without external scripts.
- Full-screen broadcast EPG overlay, and whole-content TV guide when windowed.
- Compact video controls with hover/click fade and linked bottom gradient.
- Free resizing after an initial 16:9 player presentation.
- Monochrome retro standby test card, profile avatars, restrained channel fallbacks.
- Spanish, English (US) and English (UK) based on the system language.
- Eight Linux packages: RPM, DEB, Pacman and Flatpak for x86_64 and aarch64.

Existing installation ID `com.mrseivane.Syn`, recorder and Chromecast bridge are retained for compatible upgrades. The independent SYN Plus development Alpha (`com.mrseivane.SynPlus`) is unaffected.

Requires the user's own lawful IPTV playlists or subscriptions; channels are not included.
